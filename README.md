ЛР 2 — Страницы и навигация
Реализована SPA-навигация на react-router с общим layout, типами сущности и демонстрационным массивом записей. Добавлены компонент карточки, страницы списка и подробностей по id, заглушка создания и страница неизвестного маршрута.

ЛР 3 — Формы и локальное состояние
Список записей хранится в общем состоянии с неизменяемыми обновлениями (создание, редактирование, удаление с подтверждением) и локальным фильтром со сбросом. Форма работает через отдельный черновик с валидацией и отменой без сохранения; данные живут в памяти до перезагрузки страницы с явным пояснением в интерфейсе.

ЛР 4 — Загрузка справочника по HTTP

Реализована загрузка справочника тегов из ${import.meta.env.BASE_URL}demo/tags.json через src/services/tags.ts (getTags, parseTags) и хук src/hooks/useTags.ts (useTags) с проверкой response.ok, рантайм-валидацией элементов и уникальности id, отменой запросов через AbortController при размонтировании или перезапуске, а также сохранением черновика формы при ошибках и повторных попытках.
